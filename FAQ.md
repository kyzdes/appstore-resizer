# ❓ Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Нужен ли мне сервер для этого приложения?

Технически нет - приложение работает полностью в браузере. Однако для доступа через интернет вам нужен веб-сервер (VPS, shared hosting, или бесплатные сервисы типа Vercel/Netlify).

### Безопасно ли загружать свои изображения?

Да, абсолютно безопасно. Вся обработка происходит локально в вашем браузере. Изображения не загружаются на сервер и не покидают ваш компьютер.

### Какие форматы изображений поддерживаются?

JPEG (.jpg, .jpeg) и PNG (.png). Это стандартные форматы, требуемые App Store Connect.

### Какой максимальный размер файла?

20 МБ на файл. Это более чем достаточно для скриншотов App Store.

### Сколько файлов можно загрузить одновременно?

До 10 файлов за раз.

## Технические вопросы

### Почему приложение работает в браузере, а не на сервере?

Это обеспечивает:
- Полную конфиденциальность (файлы не покидают ваш компьютер)
- Мгновенную обработку (нет задержки на загрузку/скачивание)
- Низкие требования к серверу (можно развернуть бесплатно)
- Отсутствие затрат на хранение файлов

### Какие разрешения поддерживаются?

Все актуальные разрешения iPhone для App Store Connect (декабрь 2025):
- iPhone 6.9": 1290×2796, 1320×2868
- iPhone 6.5": 1284×2778, 1242×2688
- iPhone 6.3": 1179×2556, 1206×2622

### Как происходит масштабирование?

Используется алгоритм "cover" - изображение масштабируется так, чтобы полностью заполнить целевое разрешение с сохранением пропорций. Части изображения могут быть обрезаны, но искажений не будет.

### Что делать, если исходное изображение меньше целевого разрешения?

Приложение все равно масштабирует изображение до нужного размера, но качество может быть ниже. Рекомендуется использовать исходные изображения минимум 1242×2648 px.

### Поддерживаются ли PNG с прозрачностью?

Да, но прозрачность будет заменена белым фоном, так как App Store не принимает изображения с прозрачностью.

## Развертывание

### Какие требования к VPS?

Минимальные:
- 1GB RAM
- 1 CPU core
- 10GB дисковое пространство
- Ubuntu 20.04+ или Debian 10+

### Можно ли развернуть на shared hosting?

Да! Просто соберите проект (`npm run build`) и загрузите содержимое папки `build/` на ваш хостинг.

### Нужна ли база данных?

Нет, приложение не использует базу данных.

### Можно ли использовать бесплатный хостинг?

Да! Приложение отлично работает на:
- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages
- Firebase Hosting

### Как обновить приложение после развертывания?

```bash
cd /opt/appstore-resizer
git pull
docker-compose down
docker-compose up -d --build
```

### Нужно ли настраивать SSL?

Для production - настоятельно рекомендуется. Современные браузеры могут ограничивать функциональность на HTTP сайтах.

## Использование

### Почему я не могу выбрать определенное разрешение?

Минимум одно разрешение 6.9" должно быть выбрано, так как это обязательное требование App Store Connect.

### Можно ли обрабатывать больше 10 файлов?

Нет, это ограничение установлено для производительности. Обработайте файлы партиями по 10.

### Как называются выходные файлы?

Формат: `{оригинальное_имя}_{ширина}x{высота}.{расширение}`

Пример: `screenshot1_1290x2796.jpg`

### Можно ли изменить качество JPEG?

В текущей версии - нет. Используется качество 92%, что оптимально для скриншотов App Store.

### Сохраняются ли EXIF данные?

Нет, EXIF данные не сохраняются в выходных файлах.

## Производительность

### Сколько времени занимает обработка?

Зависит от:
- Размера и количества файлов
- Количества выбранных разрешений
- Мощности вашего компьютера

В среднем: 1-5 секунд на файл.

### Можно ли ускорить обработку?

Приложение уже оптимизировано. Для ускорения:
- Используйте более мощный компьютер
- Закройте лишние вкладки браузера
- Обрабатывайте меньше файлов за раз

### Почему браузер тормозит во время обработки?

Обработка изображений - ресурсоемкая операция. Это нормально для больших файлов.

## Устранение неполадок

### Приложение не запускается локально

Проверьте:
```bash
node --version  # должна быть 18+
npm --version
npm install
npm run dev
```

### Docker контейнер не запускается

```bash
docker-compose logs  # посмотрите логи
docker-compose down
docker-compose up -d --build  # пересоберите
```

### Ошибка при загрузке файлов

Проверьте:
- Формат файла (только JPEG/PNG)
- Размер файла (макс. 20 МБ)
- Количество файлов (макс. 10)

### ZIP архив не скачивается

Проверьте настройки браузера - возможно блокируется автоматическое скачивание.

### Изображения получаются обрезанными

Это нормально - используется режим "cover" для сохранения пропорций. Если вам нужно другое поведение, используйте исходные изображения с правильным соотношением сторон.

## Безопасность

### Можно ли использовать для конфиденциальных изображений?

Да! Изображения обрабатываются только в вашем браузере и никуда не отправляются.

### Сохраняются ли логи обработки?

Нет, приложение не сохраняет логи обработанных файлов.

### Безопасно ли разворачивать на публичном сервере?

Да, но рекомендуется:
- Использовать HTTPS
- Настроить firewall
- Регулярно обновлять систему
- Использовать надежные пароли
