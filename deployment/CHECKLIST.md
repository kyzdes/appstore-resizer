# ✅ Чеклист развертывания

Используйте этот чеклист для успешного развертывания на production.

## Перед развертыванием

- [ ] VPS сервер готов (Ubuntu 20.04+ или Debian 10+)
- [ ] SSH доступ настроен
- [ ] Доменное имя указывает на IP сервера (A-запись)
- [ ] Порты 80 и 443 открыты в firewall

## Установка базовых компонентов

- [ ] Docker установлен
- [ ] Docker Compose установлен
- [ ] Nginx установлен (для production с SSL)
- [ ] Certbot установлен (для SSL сертификатов)

## Развертывание приложения

- [ ] Репозиторий склонирован в `/opt/appstore-resizer`
- [ ] Docker образ собран
- [ ] Контейнер запущен (`docker-compose up -d`)
- [ ] Приложение доступно по IP

## Настройка production (опционально)

- [ ] Nginx настроен как reverse proxy
- [ ] SSL сертификат получен и установлен
- [ ] HTTPS редирект работает
- [ ] Приложение доступно по домену через HTTPS

## Безопасность

- [ ] Firewall настроен (UFW)
- [ ] Только необходимые порты открыты (22, 80, 443)
- [ ] SSH вход по ключу (пароль отключен)
- [ ] Root вход по SSH отключен
- [ ] Автоматические обновления безопасности включены

## Мониторинг

- [ ] Логи проверены (`docker-compose logs`)
- [ ] Healthcheck работает
- [ ] Автозапуск контейнера настроен (restart: unless-stopped)
- [ ] SSL сертификат автообновляется (certbot)

## Финальная проверка

- [ ] Приложение открывается в браузере
- [ ] Загрузка изображений работает
- [ ] Конвертация работает корректно
- [ ] ZIP архив скачивается
- [ ] Все разрешения доступны для выбора
- [ ] Мобильная версия работает корректно

## После развертывания

- [ ] Создана резервная копия конфигурации
- [ ] Документация обновлена
- [ ] Команде предоставлен доступ (если нужно)
- [ ] Мониторинг настроен (опционально)
